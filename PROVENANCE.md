# Project provenance

FoodPal was developed as a team software engineering project at TU Delft.

Development took place in a private university repository using feature branches, merge requests and CI. This GitHub repository was created after the project had finished as a portfolio copy, so its commit history starts with the later import rather than the original development timeline.

My work was mainly on client-side features and integration, including the shopping-list workflow, recipe labels and filtering, timer functionality, WebSocket refresh behaviour, favorites handling, UI work and tests.

Internal course material such as meeting notes, feedback documents and university-specific repository metadata is intentionally not included here.
